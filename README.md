# luiscore-corpus

GitHub mirror of the LuisCore LLM Discovery Corpus slices published to `public/datasets/` on [luiscore.com](https://luiscore.com).

- `latest.jsonl` / `latest.csv` — most recent daily slice
- `manifest.json` — slice metadata
- `slices/` — dated exports

Canonical HuggingFace dataset: https://huggingface.co/datasets/luisprimecore/luiscore-corpus
